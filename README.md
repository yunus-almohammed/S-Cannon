# S-Cannon

S-Cannon is a Unity game project developed using C# as a training project to improve my gameplay programming skills.

## Overview

This project was created for practice and learning. It focuses on building basic gameplay systems in Unity, working with C# scripts, organizing Unity project files, and understanding the game development workflow.

## Features

- Built with Unity and C#
- Core gameplay mechanics implemented through custom scripts
- Scene-based Unity project structure
- Player interaction and game logic systems
- Organized assets inside the Unity `Assets` folder
- Prototype project created for training and practice

## Tools and Technologies

- Unity
- C#
